Why this file, in three facts

Methods and numbers →
01 · The metric

Every emitted pixel costs 0.2

DTI = TPw / (0.2·(TPw+FPw) + 0.8·|G|). False-positive mass is linear in emitted pixels; |G| (hidden new-fault pixels) is small. Official definition ↗

02 · The measurement

A blind lattice reveals the density

The owner's spacing-5 lattice scored 0.0904. A uniform lattice earns the same expected credit wherever truth is, so that one number gives the hidden truth density (≈0.24% of cells). At that density 0.2·N is ≈70% of H19-5's denominator.

03 · The precedent

Dotting already worked once

Same probability surface, solid → dotted: owner-reported 0.1280 → 0.1839 (+44%) with 60% fewer pixels. H19-4/H19-5 were never dotted. This session tests that on the best surface, under frozen rules.

What was checked

Computed in this repo

  1. Format and range

    Single band, float32, EPSG:32611, exact grid; all 5,167,373 footprint values finite in [0,1]; NaN outside. 148 owner rasters profiled: none has a value outside [0,1].

  2. Paired holdout, frozen rule

    Four spatial quadrants, 30 selection + 30 confirmation sparse-truth draws; the primary improves sparse and dense DTI and wins 120/120 fold-draw cells.

  3. Exact-file accessibility audit

    Labels first, then each raster: roads, closed claims, four acquisition blocks. Labels AUC 0.496 (chance); H19-4 prediction 0.556.

  4. Reproducibility

    The alternate raster is byte-identical to the earlier session's independently frozen candidate (SHA-256 prefix 91eae1ca).
