Evidence Rules (Parallel-Run Protocol)

  • Label every number: HOLDOUT-DTI (evaluator version, # withheld positives, 95% CI) or ORGANIZER-CONFIRMED (organizer receipt). A projection is never written as a score.
  • Leakage canary: any feature alone with AUC > 0.90 = leakage until proven otherwise. GEO1 worst AUC = 0.578 — PASS.
  • Uniqueness: raster rank-correlation ≤ 0.90 with any registry raster AND ≤ 70% of dots within 3 px of any one registry raster's dots. GEO1 surface: PASS (max|ρ| = 0.211). GEO1 dots: FAIL (99.25% > 0.70) due to space-filling calibration lattice.
  • Holdout: hide-and-recover — withhold whole fault segments with buffer, catalogue features from visible faults only, pixel-exact masking, pooled DTI (alpha 0.2, beta 0.8, 300 m triangular kernel).
  • Budget: stop after 3 experiments or 2 hours. No submission slot spent without a selector step. GEO1 used 1 experiment, 0 slots.
