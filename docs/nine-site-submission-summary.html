4. GEO1 holdout-integrity finding

The experiment card records a code SHA that matches the current source; that does not establish which bytes were actually executed. The source audit shows that in scripts/build_unique_geothermal_submission.py, the fold loop sets eligible = fp & f["valid"] & ~catalogue, where catalogue is loaded once from the full label raster. The shared SegmentHoldout contract requires fold-visible catalogue masking. Since the hidden fold positives are a subset of that full catalogue, this eligibility rule uses withheld labels in deciding which pixels may be predicted. Therefore the recorded GEO1 HOLDOUT-DTI, CI and canary pass cannot support method ranking or promotion. The original experiment files remain unchanged; the audit records source hashes and the invalid disposition in the machine-readable audit.
