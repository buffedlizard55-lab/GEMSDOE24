The raster uses zero outside the footprint and has no NaN nodata tag; its own run card sets `official_format_compliant: false`. - **Uniqueness fails:** the recorded final-dot overlap is **99.2538%** within 3 px of one of only **8 locally cached** registry rasters; the full registry has 46 entries in the run's registry snapshot. The separate spacing-5 witness bound implies at least `(129,184 - 6,649) / 129,184 = 94.8531%` overlap for that many distinct dots. Its surface screen (`|Spearman ρ| = 0.2107`) also covered only the cached subset, not the full current registry.
- **Critical holdout leakage — invalidate the reported DTI:** the script forms each validation emission mask as `fp & f["valid"] & ~catalogue`, where `catalogue` is the complete label grid read before fold evaluation. It does **not** use the fold's `f["visible"]` mask for eligibility. The full catalogue therefore removes withheld/test fault pixels from candidate placement. That is target-informed selection and violates the protocol that all catalogue-dependent masks/features be built from visible faults only. The source-reported **HOLDOUT-DTI = 0.1426949**, evaluator `gems-segment-pooled-v1`, **60,988 withheld positives**, 95% CI `[0.1322931, 0.1523671]` is therefore **COMPROMISED / NOT A VALID COMPARABLE HOLDOUT**; do not compare it with the recorded best or present it as evidence of performance. The feature-only AUC canary does not test this eligibility-mask leak. A corrected score would require a newly authorized, prospectively documented run using visible-only fold eligibility; do not silently patch and rerun this stopped experiment.
- **Redundant magnetic input:** `rtp_like` is assigned from the exact same `TMI_up150` raster as `tmi_up150`; both enter the Sobel-edge loop and are added separately. The purported TMI-edge plus “RTP proxy edge” is the same channel counted twice, not independent magnetic corroboration. `TMI_up150` is a rank-grid proxy here, not validated RTP in physical units.
- **Frozen-runner lint exception:** Ruff reports nine style/static issues in the source-hashed GEO1 experiment script (unused imports/locals, a semicolon, and a repeated import). The script is now excluded from Ruff rather than edited, because changing it would invalidate its recorded execution-code hash. This exclusion is explicit; it does not make the GEO1 metric valid or constitute a clean lint result for that file.
- **Scientific scope:** the task/evaluator is mapped-fault recovery, not direct geothermal-vent labels. A fault-propensity surface cannot establish geothermal resource or vent discovery. The stated alluvial-fan, terrace, paleoshoreline and road cut/fill mimics remain plausible confounds.

This source-level defect changes the disposition: GEO1 is a downloadable **research diagnostic only**, and its recorded DTI is untrusted for model ranking. Do not promote or spend a slot on it.
