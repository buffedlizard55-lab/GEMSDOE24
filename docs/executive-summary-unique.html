How to submit to the competition

These instructions describe the submission process. They do not authorize submitting this negative file. Only a file released by an independent scientific selector with a current quota receipt may be submitted.

  1. 1 · Download only a selector-released PASS file

    Compare its filename and SHA-256 to its hash-bound run-card receipt. Never upload a renamed historical reference, a preview image, or the feature stack. The file on this page is explicitly NOT OK TO SUBMIT.

  2. 2 · Open the official competition page

    Sign in at DrivenData GEMS, then Submit → Make new submission. The project never automates DrivenData access (its Terms of Use forbid robots).

  3. 3 · File to submit

    Choose a single-band GeoTIFF (.tif), or a .zip containing exactly one GeoTIFF. It must match the submission format's CRS (EPSG:32611), shape (3730 × 3292), and geotransform ([100, 0, 243350, 0, −100, 4508550]). All footprint values must be finite and in [0,1].

  4. 4 · Note (optional)

    Paste the packet's short comment — at most 140 characters in this project. Example from this file: 24GEMS geothermal-surface-proximity vents+springs | catalogue-independent | research; HOLDOUT-DTI 0.02235 | id dd2fff044fc1 (123 chars).

  5. 5 · Check quota and submit

    Historical rules mention three submissions per week; one final submission is chosen without seeing private scores. Confirm your remaining allowance on the DrivenData submission page before uploading. Save an artifact-linked submission-page receipt before calling any score ORGANIZER-CONFIRMED.

  6. 6 · If the portal says “Predicted values must be in range [0, 1]”

    Stop and do not rescale. (a) Confirm you chose the single-band file by SHA-256. (b) Try a zeros-outside encoding (all values finite and in [0,1], zeros outside the footprint) — this file uses that encoding. (c) Contact the organizers with the checks JSON.
