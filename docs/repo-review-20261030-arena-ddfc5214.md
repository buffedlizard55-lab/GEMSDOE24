The immutable historical artifact links and hashes are in the [champion table](historical-champions.html) and [B2 analysis](../knowledge/14_h33_analysis_2026-10-25.md).

The shared implementation uses distance-weighted Tversky:

```text
DTI = T / (T + 0.2 F + 0.8 (G - T))
```

Here `T` is distance-weighted true credit, `F` false-positive mass, `G` withheld positive mass, and `G-T` false-negative mass; credit uses the 300 m triangular kernel. Consequently, simply emitting fewer dots is not an explanation for a better score. Pruning could help only if the deleted points remove enough weighted false-positive mass while sacrificing sufficiently little true credit. Because the false-negative penalty is larger than the false-positive penalty in this formulation, indiscriminate thinning is especially unsafe. Catalogue distance alone cannot reveal the hidden true/false contribution of a removed dot. Neither the score mechanism nor a geothermal-vent discovery is established by the reported value.

A higher result is scientifically possible in principle, but this repository contains **no evidence that a new method will beat B2**, no defensible numeric forecast, and no valid current candidate to submit. The repository's source-recorded local best is a separate internal metric: **HOLDOUT-DTI 0.166060**, evaluator `gems-segment-pooled-v1`, 60,988 withheld positive pixels, 95% CI `[0.151858, 0.180339]` (S3DEP1; not replayed in this review and still negative under its selector). It is not a leaderboard estimate and must not be compared as if it were the organizer's hidden score.
