# Five fresh hypotheses for 24GEMSDOE — ranked, deduplicated, gated
Generated 2026-10-01 after (a) the full C2S2 accessibility audit
(`evidence/geoaudit.json`), (b) a line-by-line read of what siblings already tried
(13GEMSDOE `knowledge/03,05–13`, 16/19/20 registries, 7/5 aux stacks), and (c)
confirmation that the data we need is already on disk (fetched via the
`public-layers` CI-as-proxy branch). Expected-DTI ranks are qualitative planning
judgments, not forecasts; every candidate must pass the quadrant-fold gate
(`scripts/run_gate24.py` protocol) before any weekly slot is spent — the
governing rule of this repo (Maximize P(Win) = never spend a slot on a
non-promoted idea).

### What the audit changes about hypothesis design
1. Emission should **not** be aggressively de-accessibilized: predictions are
   *not* more access-explained than the catalogue (V1-clean AUC 0.611 vs 0.570,
   both within torus-shift-null noise). Residualization stays a ±0.0007 guardrail, not a lever.
2. The catalogue's strongest exploitable structure is its **own mapping process**
   (confidence fields) — using it as a feature is catalogue-predicting-itself
   (0.956 → 0.495 when the fault-distance feature is dropped), so it may only be
   used to decide **where to spend mass when geology disagrees**, never as a score surface.
3. The geology bands separate near/far *better than access does* (0.684 vs 0.570)
   — the marginal signal must therefore be **orthogonal structure inside the
   physics**, not new covariates correlated with terrain access.

## H24-1 · Confidence-contrast gap targeting (rank 1: best expected gain / cost)
* **Layers:** INGENIOUS Qfaults `FTYPE_` + `MAPSCALE` (1179 bbox traces: 739
  Well-Constrained / 351 Moderately / 89 Inferred — fetched from
  <https://web2.nbmg.unr.edu/arcgis/rest/services/Qfaults/Qfaults_INGENIOUS/MapServer/0>,
  counts verified 2026-10-01, on branch `public-layers`), plus our existing
  emission and the geology stack.
* **Signature targeted:** local *inferred-to-well-constrained trace ratio* in a
  2 km neighbourhood. Where mappers drew "Inferred" (buried) traces, parallel
  unmapped faults are likelier to exist; at 1:250k scale a real fault 1.5 km
  from a mapped one is simply absent.
* **Why it catches gaps:** the test labels *are* the experts' gap-fills; the
  catalogue's own confidence field is the only public trace of where the
  mapping process thinned out.
* **Difference from everything in-repo:** siblings used the catalogue only as
  labels/negatives (19's L-layers, 13's detectors, 16's fusion); nobody has
  used the *confidence stratification* as a spatial prior. Deliberately applied
  only as a **mass re-allocation multiplier restricted to pixels where geology
  evidence already fires** (keeps the self-prediction leak out of the score).
* **Expected DTI:** medium (moves budget between pixels without changing local
  order); **Cost:** hours. **External data:** none — already verified obtainable.

## H24-2 · Ring-fault arcuate matched filter (rank 2: highest ceiling)
* **Layers:** band_tmi_hg, band_tc, band_geod_2ndinv, openness (det_elev),
  all in the local stack.
* **Signature:** Radon-style curvature-selective matched filter for circular /
  arcuate gradient chains (radius 3–30 cells) — caldera rings and cryptodome
  annuli.
* **Why it catches gaps:** every detector this group has built is linearity
  biased (worms H-A, directional coherence H-E, cross-gradient edges R7-1,
  zero-tilt contours R7/H-B: a linear continuity tracker structurally breaks
  an arc into penalized segments). Ring faults at Steamboat Hills/Tonopah-
  springs-type systems are geothermal-target faults that the USGS/INGENIOUS
  line-trace convention under-reports.
* **Difference:** no sibling repo contains any curvature template; 13 R9-1
  ("dotted-ridge closing", LOSES) completed *along strike*, not around arcs.
* **Expected DTI:** medium-high if rings exist unlabeled; the 300 m credit
  kernel bridges short arc fragments. **Cost:** ~half a day.

## H24-3 · Acquisition-noise equalization before ensembling (rank 3: cheap robustness)
* **Layers:** GeoDAWN `acq_window` (official Area-1/Area-2 polygons — ScienceBase
  item 657e1d85d34e23d3533209f7, CC0) + all potential-field bands.
* **Signature:** 200 m vs 400 m line spacing changes the noise floor /
  small-anomaly retention of every band identically; per-window rank
  normalization removes the *systematic* band-distribution shift between
  survey domains before any model sees them (a normalization of the physics,
  distinct from emission-level residualization already gate-tested).
* **Why it catches gaps:** detector thresholds that are right for Area-2
  over/under-fire in Area-1; equalizing lets genuinely subtle Area-1 traces
  compete for budget on merit.
* **Difference:** the audit measured acquisition structure (this repo, new);
  nobody *corrected* bands for it. 15GEMSDOE's acquisition audit documented the
  spacing; the fix is novel here.
* **Expected DTI:** small but fold-uniform (variance reduction); **Cost:** low.

## H24-4 · Damage-zone texture anisotropy from residual fields (rank 4)
* **Layers:** residual of band_tmi after per-window de-trending, band_iso_grav
  residual, geod_dilaterate — local 2-θ anisotropy of the *semi-variogram range*
  in 1 km windows.
* **Signature:** fault damage zones align fracturing → directional autocorrelation;
  present without any discrete edge (buried, vegetation-masked traces).
* **Why it catches gaps:** catalogue omissions cluster exactly where no edge is
  visible; texture persists where amplitude contrast dies.
* **Difference:** distinct from H-E (global directional coherence on amplitude)
  and R11 #1 (earthquake focal planes, external data): different estimator
  (variogram), different field (residual physics), different scale (1 km window).
* **Expected DTI:** low-medium; texture features have historically underperformed
  here (conj_alteration, strain bands). **Cost:** half a day.

## H24-5 · Sinter-ridge *linear* seeds (rank 5: the vent-flavored shot)
* **Layers:** `d_sinter_px` (USGS GDR sinter/kaolin deposits, already in
  confounds), openness + deq_n100a15 coherence; seed only *linear* sinter
  alignments ≥3 px (silcrete ridge creep along fault scarps).
* **Why it catches gaps:** paleo-outflow ridges mark the vent-proximal segment
  of structures that lack any topographic scarp; INGENIOUS' stated goal is
  "hidden" systems (GDR 1391).
* **Difference:** 20GEMSDOE pindrop seeded *points* at vent distance (0.1193
  live); this uses the *ridge morphology* of sinter fields and is line-seeded.
* **Expected DTI:** low; the only candidate speaking to the geothermal-vent
  framing of the program (kept for science as much as score). **Cost:** day.
