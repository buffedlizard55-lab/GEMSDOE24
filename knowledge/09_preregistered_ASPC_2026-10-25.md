## Fixed experiment

1. Decode quantization using checked-in metadata: `t=(q-1)/254`; sqrt-encoded quantities invert as `x=xmax*t*t`. Zero is missing. Match band descriptions, CRS, shape, affine transform and cache SHA256 before using.
2. Let U,D,C be decoded upface/downface/cross maxima (same units); `A=U/(U+D+C+0.001)`; `V=1-C/(U+D+C+0.001)`; curvature balance `B=2*sqrt(N*P)/(N+P+1e-6)`; step response `S=step/(step+0.05)`; `H=clip(coh100,0,1)`. Fixed surface `A*V*B*S*sqrt(H)`. Require positive decoded coverage fraction and all needed bands valid. This is an uncalibrated ranking, not a probability model.
3. Test every input alone and every derived factor on held-out positives using AUC; an AUC above 0.90 **or below 0.10** triggers leakage quarantine (inversion is equally diagnostic). Missing/single-class tests fail closed. No learned or catalogue-derived surface features. No thresholds are fitted on holdout outcomes.
4. Extend the shared `gems.holdout` with versioned segment hide-and-recover: four spatial quadrants; hide whole 8-connected catalogue components touching the test quadrant; expose none of those components outside the quadrant; training mask excludes a 30-pixel (3 km) buffer around held-out components and the test quadrant. This conservative component grouping is not an expert fault-segment inventory. Score only in the test quadrant; mask visible faults pixel-exactly. Count whole withheld and scored withheld positives separately.
5. Placement: deterministic descending surface, row-major tie break, minimum Euclidean dot distance 3 px. Budget 37,654 full-footprint dots; per-fold budget proportional to footprint area, rounded independently. Stop if insufficient supported positive locations; never inject random dots. No 200 m catalogue halo: only visible pixels are excluded. The final full-data file masks known faults exactly.
6. Before placement check surface Spearman correlation against every reference in the downloaded registry, on the entire common finite footprint. Constants are reported as undefined/noninformative, never a zero correlation. On final dots check Spearman again and directional fraction within **inclusive 3 px** of every registry reference. `rho > 0.90` or overlap `> 0.70` means duplicate: log and stop, no alternate experiment to evade it. Check both candidate-to-reference and reverse coverage; the requested stop criterion is candidate-to-reference.
7. Shared exact DTI, alpha=0.2, beta=0.8, 300 m triangular kernel, summed TP/FP/FN over folds then ratio. CI from spatial tile cluster bootstrap of pooled components (20 km cells, 1,000 resamples, fixed seed). Compute metric distance globally within each fold, not independently per bootstrap tile. CI is conditional on these quadrants/catalogue, not hidden-set performance.
8. Compare against fixed **label-free** scarp-amplitude control at identical emission policy and budgets. Also report shipped peers only as contaminated descriptive diagnostics, not true OOF best. Current-best OOF reconstruction absent: **cannot establish promotion**, even if the control loses. No leaderboard extrapolation.
9. Writer reopens final bytes; require one band float32, finite [0,1] inside, zero outside for conservative all-finite research download, matching CRS/shape/transform and SHA256. Use existing template, never its pixel values as predictions.
10. Run card has negative verdict unless all requirements including an assigned lane and comparable current-best OOF evidence pass. Separate format-valid, distinct-vs-reviewed-registry, holdout-beats-control, promotion-qualified, and selector-authorized. The lane never spends slots; selector authorization stays false.
