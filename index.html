Verdict (three findings, each falsifiable): (1) The headline AUC 0.956 for “access explains the catalogue” is an artefact — dropping the single INGENIOUS fault-distance feature collapses it to chance (leave-one-out: 0.495); the catalogue was predicting its own geometry. (2) With genuinely non-geological access features only (V1 clean), the classifier reaches 0.570 on the labels and fails the torus-shift null (margin -0.060, p 0.444) → the accessibility-confounding hypothesis is NOT confirmed at this feature set and 100 m resolution; geology-only (0.684) separates near/far better than access does. (3) The overfitting kill-criterion (“predictions as explained by access as the labels”) did not fire: predictions V1-clean 0.611 vs labels 0.570 — both within shift-null noise, so our current emission's gains are not mapping-process overfitting.
